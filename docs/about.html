我在意的事

我做前端的时间不算短，但真正让我留下来的，是那种「把一个界面调顺」的满足感： 段落的行高刚刚好，按钮按下去有轻微的下压，深色模式下颜色不刺眼， 键盘 Tab 一圈走下来每处焦点的位置都清清楚楚。

我尽量不用框架去搭个人项目，因为从零写一遍 CSS 能让我重新想起浏览器本来就很能干。 这个网站就是这样一个练习：没有构建工具，双击 index.html 就能看。
