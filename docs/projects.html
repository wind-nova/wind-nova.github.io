项目与作品

这里放着我做过的六件事，有大有小。多数是练习，少数真的有人在用， 但它们都遵守同一条规则：先能用，再好看。

  • 静态个人站模板

    零依赖、可直接部署到 GitHub Pages 的个人网站模板，带浅色 / 深色主题与响应式导航。

    • HTML
    • CSS 变量
    • 无构建

  • 色彩令牌小工具

    输入几个主色，自动生成一套带浅色 / 深色两套值的 CSS 变量，并检查对比度是否达标。

    • JavaScript
    • 色彩

  • 安静的番茄钟

    没有音效、没有弹窗，只有一圈缓慢收缩的圆。工作 25 分钟，然后起身走走。

    • Vanilla JS
    • SVG

  • 可访问性自查清单

    把 WCAG 里最常被忽略的 30 条整理成一份可勾选的清单，配合浏览器插件一起用。

    • a11y
    • 文档

  • Markdown 写作台

    左边写、右边读，支持本地草稿保存。写周报和长文都靠它。

    • JavaScript
    • localStorage

  • 桌面角落天气

    一个只有 200 行的小挂件，用柔和的小图标显示今天的天气和温度。

    • API
    • CSS 动画
